# «Материальный вопрос»

Второй роман проекта: бытовая магическая комедия с эротическими элементами. Отдельная книга, не связанная сюжетом с «Контуром общего».

Мастер по ремонту из небольшого города, по уши в долгах, находит артефакт и получает власть над материей. Вместо войны со злом он решает самую насущную задачу — как жить, не считая каждую копейку. Выясняется, что деньги нужны гораздо реже, чем кажется: многое можно сделать самому, а нужное всем — сделать и обменять на то, чего пока не умеешь. Дальше он разбирается, как устроена сила, и пробует научить ей других.

## Аудио и видео

Готовые файлы глав лежат в `media/`: озвучка (`.mp3`), субтитры (`.srt`), обложка (`.png`) и видео с обложкой и вшитыми субтитрами (`.mp4`).

Озвучка делается локально синтезатором RHVoice (голос `aleksandr-hq`), без внешних сервисов:

```bash
sudo apt install rhvoice rhvoice-russian ffmpeg
pip install pillow
python novel-materia/tools/make_media.py --chapter 01-minus-sorok-sem-tysyach
```

Параметры: `--voice` (другой голос RHVoice, например `artemiy` или `mikhail`), `--rate` (темп в процентах, по умолчанию 125), `--no-video` (только аудио и субтитры).
