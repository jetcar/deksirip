# «Материальный вопрос»

Второй роман проекта: бытовая магическая комедия с эротическими элементами. Отдельная книга, не связанная сюжетом с «Контуром общего».

Мастер по ремонту из небольшого города, по уши в долгах, находит артефакт и получает власть над материей. Вместо войны со злом он решает самую насущную задачу — как жить, не считая каждую копейку. Выясняется, что деньги нужны гораздо реже, чем кажется: многое можно сделать самому, а нужное всем — сделать и обменять на то, чего пока не умеешь. Дальше он разбирается, как устроена сила, и пробует научить ей других.

## Документы

- [00-plan.md](00-plan.md) — замысел, правила магии, персонажи, экономические линии, структура в трёх актах и поглавный план.

## Статус

Готов план. Написана глава 1; главы лежат в `chapters/`.

## Аудио и видео

Готовые файлы глав лежат в `media/`: озвучка (`.mp3`), субтитры (`.srt`), обложка (`.png`) и видео с обложкой и вшитыми субтитрами (`.mp4`).

Озвучка делается локально нейросетевым синтезатором Silero (модель `v5_ru`, голос `eugene`), без внешних сервисов; модель скачивается один раз:

```bash
pip install silero omegaconf torch pillow   # и ffmpeg с libass
python novel-materia/tools/make_media.py --chapter 01-minus-sorok-sem-tysyach
```

Параметры: `--voice` (другой голос Silero: `aidar`, `baya`, `kseniya`, `xenia`), `--engine rhvoice` (старый синтезатор RHVoice, голос `aleksandr-hq`, `--rate` — темп в процентах), `--no-video` (только аудио и субтитры). Обложка `.png` создаётся, только если её ещё нет.

### YouTube

Отдельный плейлист «Материальный вопрос — аудиокнига» на том же канале, что и первая книга (тот же `book/tools/client_secret.json` и токен):

```
pip install google-api-python-client google-auth-oauthlib
python novel-materia/tools/upload_youtube.py --login --all
```

Скрипт загружает каждую главу из `media/`, у которой ещё нет `<глава>.uploaded.json`, с обложкой и субтитрами, создаёт плейлист (`media/playlist.json`) и раскладывает главы по порядку. После переозвучки `--all --replace` заново загружает главы, у которых изменилось видео, меняет их в плейлисте и делает старые видео приватными. На загрузку тратится дневная квота YouTube API (около пяти видео в день); когда она кончается, скрипт пишет, когда она обновится, а повторный запуск продолжает с того же места. Файлы `*.uploaded.json` и `playlist.json` нужно закоммитить, чтобы главы не загружались повторно. Если положить содержимое `youtube_token.json` в переменную окружения `YOUTUBE_TOKEN_JSON`, загрузка работает без браузера, в том числе из ежечасной задачи.
