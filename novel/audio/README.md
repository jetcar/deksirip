# Аудиоверсия

## Прослушивание на компьютере

Для завершённой второй редакции откройте `offline-player-v2.html`: это автономный плеер, в который встроены пролог и все 32 главы. Он работает без локального сервера, позволяет выбрать главу, русский голос и скорость, ставить чтение на паузу и автоматически переходить к следующей главе.

`offline-player.html` сохранён для первой редакции.

После изменения второй редакции обновите её плеер командой:

```powershell
& .\novel\tools\build-offline-player.ps1 -ChapterDirectory .\novel\chapters-v2 -Output .\novel\audio\offline-player-v2.html
```

## MP3 по желанию

Здесь также можно сохранять MP3-файлы по одному на главу. По умолчанию используется русский голос `ru-RU-SvetlanaNeural` в слегка замедленном темпе.

Первый файл создаётся для проверки звучания. Остальные главы можно генерировать по требованию через `../tools/make-audio.ps1`.

Примеры из корня проекта:

```powershell
& .\novel\tools\make-audio.ps1 -Chapter 01-chelovek-s-cenoy
& .\novel\tools\make-audio.ps1 -All
```

Для мужского голоса добавьте `-Voice ru-RU-DmitryNeural`.
