# Вычисления

Здесь находятся исходные данные, таблицы, формулы и результаты количественной проверки модели.

## Структура

- [sweden/](sweden/) — расчёт необходимого труда для базового уровня жизни в Швеции.

## Правила расчётов

- исходные данные отделяются от предположений;
- физические величины не смешиваются с денежными;
- все результаты считаются как минимум для трёх сценариев рабочего времени;
- каждая оценка содержит источник, дату и диапазон неопределённости;
- отсутствие данных обозначается `TBD`, а не заменяется догадкой.
