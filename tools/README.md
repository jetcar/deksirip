# Скрипты

Все скрипты репозитория лежат здесь, по папке на проект:

| Папка | Проект | Скрипты |
|---|---|---|
| `book/` | книга «Куда ушёл излишек» (`book/`) | `synthesize_audio.py`, `make_video.py`, `upload_youtube.py`, `make_short.py`, `telegram_post.py`, `make_vk_images.py`, `stress.py` |
| `materia/` | роман «Материальный вопрос» (`novel-materia/`) | `make_media.py`, `make_scene_video.py`, `upload_youtube.py` |
| `shestoy/` | роман «Шестой пункт» (`novel-shestoy-punkt/`) | `make_media.py`, `upload_youtube.py` |
| `secrets/` | ключи и токены, общие для всех | `client_secret.json`, `youtube_token.json`, `telegram_token.txt` — не коммитятся |

## Правила

1. Запускать из корня репозитория: `python tools/<проект>/<скрипт>.py ...`. Скрипты от текущей папки не зависят, поэтому из папки проекта тоже можно: `cd book; python ../tools/book/upload_youtube.py` (так работают задачи книги). Относительные пути в аргументах считаются от текущей папки.
2. Новый скрипт кладётся в `tools/<проект>/`, а не в папку с текстом. Для нового проекта — новая подпапка и строка в таблице выше.
3. Скрипт находит свой проект сам: `ROOT = Path(__file__).resolve().parents[2] / "<папка проекта>"`; секреты — в `parents[1] / "secrets"`. Не полагаться на текущую папку.
4. Скрипты одного проекта импортируют друг друга по имени (`from make_media import ...`); между проектами не импортировать — скопировать нужное.
5. Ключи, токены и прочие секреты — только в `tools/secrets/`, она в `.gitignore`.
6. Записи о загрузках (`*.uploaded.json`, `playlist.json`) и прочие результаты лежат в папке проекта, а не здесь, и коммитятся вместе с ней.
7. У каждого скрипта в начале docstring с примером запуска; `--help` должен работать без сети и токенов.
