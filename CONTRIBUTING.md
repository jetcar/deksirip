# Как участвовать

Проект предназначен для добросовестной проверки модели, а не для подтверждения заранее выбранного вывода.

Хорошее возражение содержит:

- конкретное предположение модели;
- причинную цепочку `X → стимул → поведение → последствие`;
- указание, является ли проблема новой для модели или общей для существующих систем;
- исторический пример, данные, расчёт или предложение эксперимента.

Не следует считать достаточным аргументом фразы «люди жадные», «это уже пробовали» или «капитализм тоже не идеален» без механизма и сравнения.

При изменении модели указывайте, какое исходное предположение изменено и какие последствия это имеет для остальных разделов.
