## Description
Толстая тетрадь в клеёнчатой обложке, в которую Лера записывает опыты с Тимой (с ch.15; раньше — «опыт номер один» на видео и тетрадь ch.08). Таблицы по линейке, графы «съедено, в пирожках», «прочность, в граммах», «время, в минутах», «примечания» (самая широкая).
## Rules / Constraints
- «Серия первая. Точность и понимание» (ch.15): 4 нити из хлопка — 120 / 260 / 410 / >900 г при 2+½ термоса / 1,5 / 1 / 0,5 пирожка; примечания («мочалка из бани, где моются тоской», «Скрепка кафедры оказалась слабее понимания»).
- «Серия вторая» (ch.15): «Опыт первый. Кнопки целы»; утренняя запись о кровати из раскладушки — размеры, форма, пружины, «в состоянии, близком к потере контроля» (подчёркнуто), «съедено — неизвестно», «Батарея подсобки — ледяная. Источник — отопление корпуса», «Ни одна кнопка не пострадала»; схема.
- «Серия третья» (запланирована): есть ли способность у Леры.
- Образцы должны храниться при журнале; нить №4 утрачена — у Шурупа.
## Story Relevance
Превращает истории о силе в числа («это не история, это кривая») — основа возможной статьи Леры; одновременно — письменный документ о секрете Тимы.
